# Δεύτερη Όραση (SecondVision)

Εφαρμογή για **τυφλούς και άτομα με μειωμένη όραση**: αναγνωρίζει αντικείμενα, πρόσωπα και κείμενο σε πραγματικό χρόνο και
μιλάει ελληνικά. Ελέγχεται **αποκλειστικά με τη φωνή**. Τρέχει σε κινητό (Chrome/Android ιδανικά), σαν κολιέ ή σε καπέλο,
και **όλη η επεξεργασία γίνεται τοπικά στη συσκευή** — χωρίς internet, χωρίς αποστολή εικόνων.

Συνέχεια του προηγούμενου πρότυπου «Έξυπνος Βοηθός Όρασης» (COCO-SSD) με πολύ ισχυρότερα μοντέλα και νέες δυνατότητες.

## Τι κάνει

| Δυνατότητα | Πώς |
|---|---|
| **«Βρες τα κλειδιά»** | Ο χρήστης γυρίζει αργά 360°. Η εφαρμογή συνδυάζει την κάμερα με την πυξίδα, βρίσκει το αντικείμενο και λέει «γυρίστε δεξιά 40 μοίρες», με μπιπ που αλλάζουν τόνο/ρυθμό/στερεοφωνική θέση ώσπου να το έχει μπροστά του. |
| **Μνήμη «πού το άφησα»** | Κάθε φορά που βλέπει ένα αντικείμενο καταγράφει πότε, προς ποια κατεύθυνση, σε τι απόσταση και σε ποιο αποθηκευμένο μέρος (GPS). «Πού άφησα το πορτοφόλι;» |
| **Εκμάθηση νέων αντικειμένων** | «Μάθε αυτό ως κλειδιά» — το COCO δεν γνωρίζει κλειδιά, πορτοφόλι, γυαλιά κλπ. Η εφαρμογή μαθαίνει οτιδήποτε από λίγα δευτερόλεπτα βίντεο (embeddings MobileNetV3). |
| **Πρόσωπα** | «Αυτός είναι ο Γιάννης» — μετά τον αναφέρει με το όνομά του. Τα δεδομένα μένουν μόνο στη συσκευή. |
| **Σάρωση 360°** | «Κάνε σάρωση» — περιγράφει τι υπάρχει γύρω με θέσεις ρολογιού («καρέκλα στις 3, τραπέζι στις 6»). |
| **Φωνητικές ρυθμίσεις** | «Πιο δυνατά / πιο σιγά», «μην λες καρέκλες», «πες τα αυτοκίνητα πιο δυνατά», «ένταση 7», «πιο αργά», «λιγότερα/περισσότερα». Ένταση και σίγαση **ανά αντικείμενο**. |
| **Περπάτημα** | Λειτουργία που ειδοποιεί μόνο για εμπόδια, ανθρώπους, ζώα και οχήματα. Προειδοποιήσεις κινδύνου (όχημα που πλησιάζει) διακόπτουν κάθε άλλη φωνή, με ήχο και δόνηση. |
| **Ανάγνωση κειμένου** | «Διάβασε» — OCR ελληνικών/αγγλικών (ταμπέλες, ετικέτες, αλληλογραφία). |
| **Τόποι & πλοήγηση** | «Θυμήσου αυτό το μέρος ως σπίτι», «οδήγησέ με στο σπίτι» (GPS + πυξίδα + μπιπ). |
| **Μέσα σε όχημα** | «Είμαι σε αυτοκίνητο» → σταματούν οι προειδοποιήσεις για οχήματα (συνεχίζουν τα υπόλοιπα). «Βγήκα από το αυτοκίνητο» → επιστρέφουν. Αν οι προειδοποιήσεις επαναλαμβάνονται συνεχώς (ή η ταχύτητα GPS είναι >18 χλμ/ώρα), η εφαρμογή ρωτά μόνη της αν είστε σε όχημα. |
| **«Τι είναι αυτό;»** | «Τι μπουκάλι είναι αυτό;», «τι αντικείμενο είναι αυτό;» → διαβάζει την ετικέτα (OCR, τοπικά) και ψάχνει στη Wikipedia με λέξεις (όχι εικόνα). Προαιρετικά, με δικό σας κλειδί Claude API στις Ρυθμίσεις, στέλνει τη φωτογραφία του αντικειμένου για πλήρη αναγνώριση προϊόντος — μόνο όταν το ζητήσετε. Χωρίς internet το λέει καθαρά. |
| **Αναλυτική περιγραφή (cloud)** | «Περίγραψε αναλυτικά» → ένα cloud μοντέλο όρασης (Gemini ή Claude, με δικό σας κλειδί) περιγράφει ολόκληρη τη σκηνή, χωρίς τον περιορισμό των 80 κατηγοριών. Το «τι είναι αυτό» ρωτά στη συνέχεια αν να θυμάται το αντικείμενο, και το αποθηκεύει τοπικά ώστε την επόμενη φορά να το αναγνωρίζει μόνη της. Στο Gemini αν το όνομα μοντέλου λείπει ή δεν υπάρχει, επιλέγεται αυτόματα το καλύτερο διαθέσιμο. |
| **Αυτόματο φλας** | Ανάβει σε χαμηλό φωτισμό (όπου το υποστηρίζει η συσκευή). |
| **Χωρίς internet** | PWA με service worker· τα μοντέλα είναι μέσα στο repo (`vendor/`). |
| **Εξοικονόμηση μπαταρίας** | «Μαύρη οθόνη» (OLED) — συνεχίζει να δουλεύει· ένα πάτημα = ομιλία, δύο = επαναφορά. Κρατά την οθόνη ενεργή (Wake Lock). |
| **Hands-free** | Προαιρετική συνεχής ακρόαση: «Όραση, βρες τα κλειδιά». |

### Παραδείγματα εντολών

```
βρες τα κλειδιά          τι βλέπεις              κάνε σάρωση           διάβασε
πού άφησα το κινητό      μάθε αυτό ως κλειδιά    αυτός είναι ο Γιάννης  ξέχασε τα κλειδιά
πιο δυνατά / πιο σιγά    ένταση 7                μην λες καρέκλες       λέγε ξανά καρέκλες
περπάτημα / εξερεύνηση   άναψε το φακό           θυμήσου αυτό το μέρος ως σπίτι
οδήγησέ με στο σπίτι     μαύρη οθόνη             μπαταρία / τι ώρα      βοήθεια / σταμάτα
```

## Εκτέλεση

Η κάμερα, ο προσανατολισμός και η φωνή απαιτούν **HTTPS** (ή `localhost`).

```bash
node tools/serve.mjs 8080      # τοπικά: http://localhost:8080
```

Για χρήση στο κινητό ανεβάστε τον φάκελο σε οποιονδήποτε στατικό host με HTTPS (GitHub Pages, Vercel, Netlify…) και
«Προσθήκη στην αρχική οθόνη». Δεν υπάρχει βήμα build.

Την πρώτη φορά (με internet) ανοίξτε την εφαρμογή και, από τις Ρυθμίσεις, πατήστε **«Προφόρτωση όλων»** ώστε να
αποθηκευτούν και τα προαιρετικά μοντέλα (ακριβές μοντέλο, πρόσωπα, OCR). Μετά δουλεύει χωρίς σύνδεση.

### Μοντέλα και βιβλιοθήκες (`vendor/`)

Δεν γίνονται λήψεις στο runtime. Για ανανέωση: `./tools/vendor.sh`.

| Σκοπός | Τεχνολογία |
|---|---|
| Ανίχνευση αντικειμένων (80 κατηγορίες) | MediaPipe Tasks Vision · EfficientDet-Lite0 (γρήγορο) / Lite2 (ακριβές) |
| Νέα αντικείμενα | MediaPipe ImageEmbedder · MobileNetV3-small (πολυκλιμακωτή σάρωση πλακιδίων + cosine similarity) |
| Πρόσωπα | face-api.js · TinyFaceDetector + FaceRecognitionNet (128-d) |
| Κείμενο | Tesseract.js · `ell` + `eng` |
| Φωνή | Web Speech API (`el-GR`) |

## Αρχιτεκτονική

```
index.html · css/app.css · manifest.webmanifest · sw.js
js/app.js        βρόχος ανίχνευσης, εντολές, αναζήτηση/σάρωση/πλοήγηση, εκμάθηση, UI
js/commands.js   αναλυτής ελληνικών φωνητικών εντολών (καθαρός κώδικας, με τεστ)
js/spatial.js    κατεύθυνση κάμερας από αισθητήρες, εκτίμηση απόστασης, φράσεις καθοδήγησης (με τεστ)
js/vision.js     ανιχνευτής + embedder + φωτεινότητα καρέ
js/faces.js · js/ocr.js · js/tracker.js · js/memory.js (IndexedDB) · js/sensors.js · js/speech.js · js/audio.js · js/camera.js
js/lang-el.js    ονόματα/πληθυντικοί/μεγέθη κλάσεων COCO στα ελληνικά
```

Πώς δουλεύει η καθοδήγηση: από `deviceorientation` υπολογίζεται προς πού κοιτάει η πίσω κάμερα (azimuth) ακόμη και με
το κινητό όρθιο. Το κέντρο κάθε πλαισίου δίνει γωνία μέσα στο πεδίο όρασης· άθροισμα = απόλυτη κατεύθυνση του
αντικειμένου. Αυτή αποθηκεύεται και συγκρίνεται με τη τρέχουσα κατεύθυνση ώστε να λέγεται «δεξιά 40°».
Η απόσταση εκτιμάται από το μέγεθος του πλαισίου και το τυπικό μέγεθος του είδους (π.χ. άνθρωπος 1,7 μ.).

## Περιορισμοί (ειλικρινά)

- **Δεν είναι υποκατάστατο μπαστουνιού/σκύλου οδηγού.** Οι αποστάσεις είναι προσεγγιστικές· δεν ανιχνεύονται σκαλιά,
  λακκούβες, γυάλινες επιφάνειες. Χρήση ως συμπλήρωμα και, στην αρχή, με δοκιμές παρουσία βοηθού.
- **Φωνητικές εντολές:** το `SpeechRecognition` στο Chrome Android συνήθως χρειάζεται internet. Χωρίς σύνδεση υπάρχουν
  τα κουμπιά (μεγάλα, με ετικέτες για TalkBack). Η σύνθεση φωνής δουλεύει offline αν υπάρχει εγκατεστημένη ελληνική φωνή
  (Ρυθμίσεις Android → Text-to-speech).
- **Νέα αντικείμενα:** δουλεύουν καλύτερα σε κοντινή/μεσαία απόσταση και όταν δείξετε το αντικείμενο από 2–3 πλευρές.
  Πολύ μικρά αντικείμενα σε μεγάλη απόσταση (κλειδιά στο πάτωμα 3 μ. μακριά) αναγνωρίζονται δύσκολα.
- **GPS σε εσωτερικούς χώρους** είναι ανακριβές· η «μνήμη θέσης» αντικειμένων στηρίζεται κυρίως στην πυξίδα όταν ο χρήστης
  είναι στο ίδιο σημείο, και στα ονομασμένα μέρη όταν όχι.
- **iOS:** η πυξίδα βαθμονομείται από το `webkitCompassHeading`· ο φακός δεν ελέγχεται από web εφαρμογές.
- **Πρόσωπα:** χρησιμοποιήστε μόνο με τη συναίνεση των ατόμων. Τα δεδομένα είναι τοπικά και διαγράφονται με «ξέχασε όλα τα πρόσωπα».

## Επόμενα βήματα (ιδέες)

- Εξωτερική κάμερα (καπέλο/γυαλιά) μέσω Bluetooth/Wi-Fi: η πηγή εικόνας είναι ήδη αφαιρεμένη (`js/camera.js`)· υποστήριξη WebRTC/MJPEG από ESP32-CAM ή δεύτερο κινητό.
- Ισχυρότερο μοντέλο ανοιχτού λεξιλογίου (π.χ. OWL-ViT/YOLO-World μέσω ONNX/WebGPU) για αναζήτηση «οτιδήποτε» χωρίς εκμάθηση.
- Εκτίμηση βάθους (Depth-Anything-small) για αξιόπιστες αποστάσεις και ανίχνευση σκαλοπατιών/κενού.
- Αναγνώριση χαρτονομισμάτων, χρωμάτων, φαναριών πεζών, ετικετών φαρμάκων/barcode.
- Προαιρετική «βαθιά περιγραφή» σκηνής με cloud μοντέλο όρασης (opt-in, με ρητή συγκατάθεση).
- Έκτακτη επαφή: «κάλεσε βοήθεια» με αποστολή τοποθεσίας σε συγγενή.
- Πολλαπλές γλώσσες, ρυθμιζόμενη λέξη-κλειδί, εξαγωγή/εισαγωγή μνήμης, συγχρονισμός μεταξύ συσκευών (κρυπτογραφημένος).
- Εκπαίδευση με ομάδες χρηστών τυφλών: δοκιμές χρηστικότητας με φορέα (π.χ. ΚΕΑΤ/Πανελλήνιος Σύλλογος Τυφλών).
